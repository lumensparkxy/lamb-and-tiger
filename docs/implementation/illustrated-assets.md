# Illustrated play assets

Generated with the built-in image generation tool on 2026-10-18 for the user-selected storybook direction (D044).

- `woodland_board.png` and `woodland_board_portrait.png`: rounded forest/sage foliage, small rocks and trunks restricted to corners; broad pale ivory center. No board, nodes, text or controls.
- `tiger_portrait.png`: friendly orange tiger head, cream muzzle, dark outlines, transparent background.
- `lamb_portrait.png`: friendly ivory lamb head, pink ears, dark outlines, transparent background.

Artwork is decorative. Compose renders the approved board from engine geometry, with distinct triangular tiger and circular lamb tokens. No generated board lines or words are used as functional UI. Android scales the PNG resources; the art adds no permissions or runtime network requests.
